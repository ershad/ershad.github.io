Some ideas need more room than a short message. A debugging story, a useful command, or a photograph from a walk can all be worth keeping somewhere you can return to.

This is a sample post for that space. It starts with plain Markdown and leaves room for images, code, and the occasional interesting thing from elsewhere on the web.

## Small things, written down

A useful post doesn't have to be an essay. Sometimes it's just a command you keep forgetting, together with enough context to make it useful next time.

```sh
# Start a local preview of a Jekyll site.
bundle exec jekyll serve
```

Other times, it might be a few notes:

- What I was trying to do.
- What surprised me along the way.
- What I'd try differently next time.

> Leave enough context for your future self.
